# 5G AI Network Optimizer

An AI-assisted 5G/V2I network optimization platform based on my MASc research.

This project reimplements validated MATLAB-based Connected and Autonomous Vehicle (CAV) optimization models in Python, exposes them through FastAPI and MCP, and allows AI agents to invoke deterministic network-analysis tools instead of generating numerical results themselves.

---

## What It Does

The application analyzes the tradeoff between wireless connectivity and traffic performance in a CAV V2I network.

Given parameters such as:

- required data-rate threshold
- wireless path-loss exponent

the model calculates:

- optimal base station density
- achievable wireless data rate
- optimal vehicle speed
- traffic flow

The project also supports:

- scenario comparison
- threshold sweeps
- AI-assisted explanation of results
- interactive frontend visualization
- MATLAB-style plots for multiple path-loss exponents

---

## AI-Assisted Analysis

Gemini is used as an interpretation layer rather than as the source of numerical calculations.

For example, a user can ask:

> Compare 900 Mbps and 1 Gbps for a path-loss exponent of 3.

The AI calls the deterministic Python optimization model, receives the calculated results, and explains the tradeoffs in natural language.

This keeps the mathematical model as the source of truth and reduces the risk of the AI inventing numerical results.

## Architecture

```text
Original MATLAB Thesis Model
            ↓
Validated Python Optimizer
            ↓
   ┌────────┼─────────┐
   ↓        ↓         ↓
FastAPI   Gemini     MCP Server
   ↓      Tools         ↓
Web App            AI Clients
   ↓
Interactive Charts
```

The system separates the numerical model, application interfaces, and AI layer.

### Computation Layer

The Python optimizer contains the validated mathematical model.

### API Layer

FastAPI exposes the optimizer to the web application.

### AI Layer

Gemini uses tool calling to invoke deterministic optimization functions and explain the results.

### MCP Layer

The Model Context Protocol server exposes the optimization functions as standardized AI tools that MCP-compatible clients can discover and invoke.

## Example AI Query

A user can ask:

```text
Compare 900 Mbps and 1 Gbps for alpha 3.
```

The application returns structured optimization results and an AI-generated explanation of how the data-rate requirement affects:

- base station density
- achievable rate
- vehicle speed
- traffic flow

For example, increasing the data-rate requirement generally requires denser infrastructure and can reduce the optimal vehicle speed and resulting traffic flow under the model constraints.

---

## Threshold Sweep Analysis

The application can analyze network performance over a range of required data rates.

Example:

```text
How does traffic flow and BS density change from 900 Mbps to 1.1 Gbps for alpha 3?
```

The backend evaluates multiple points across the range and the frontend renders:

- Traffic Flow vs Data Rate Threshold
- Optimal BS Density vs Data Rate Threshold

---

## MATLAB-Style Multi-Alpha Analysis

The application can recreate the type of analysis used in the original MATLAB research by evaluating multiple wireless path-loss exponents.

Currently supported:

```text
alpha = 2
alpha = 3
alpha = 4
```

The frontend plots all three curves on the same figures, allowing the impact of path-loss conditions to be compared visually.

## MCP Tools

The project includes an MCP server that exposes the network optimizer as standardized AI tools.

Current tools:

```text
optimize_network_scenario
compare_network_scenarios
analyze_threshold_range
```

For example:

```text
optimize_network_scenario
```

Inputs:

```text
data_rate_threshold = 1000000000
path_loss_exponent = 3
```

The MCP server invokes the same validated Python optimizer used by the FastAPI application.

This allows MCP-compatible AI systems to discover and use the network-analysis capabilities without requiring a custom integration for each client.

## Research Background

This project is based on my MASc research in Electrical Engineering and Computer Science at York University.

The original research investigated Connected and Autonomous Vehicle traffic-flow optimization under 5G Vehicle-to-Infrastructure communication constraints.

The work considered factors including:

- base station density
- handoff behavior
- wireless data-rate requirements
- vehicle speed
- safety constraints
- traffic flow
- path loss

The original analytical models and simulations were implemented in MATLAB.

This project modernizes that work into a Python-based software and AI platform.

## Setup

### Clone the repository

```bash
git clone <your-repository-url>
cd 5g-ai-network-optimizer
```

---

### Create a Python 3.12 virtual environment

Using `uv`:

```bash
uv venv --python 3.12 .venv
```

Activate it:

```bash
source .venv/bin/activate
```

---

### Install dependencies

```bash
uv pip install numpy scipy fastapi uvicorn google-genai matplotlib "mcp[cli]"
```

Install the project in editable mode:

```bash
uv pip install -e .
```

---

## Gemini API Key

The Gemini integration requires an API key.

Set it as an environment variable:

```bash
export GEMINI_API_KEY="your-api-key"
```

Do not commit API keys to GitHub.

## Design Philosophy

The AI model is not responsible for performing the underlying network calculations.

Instead:

```text
User Question
      ↓
AI Agent
      ↓
Deterministic Tool Call
      ↓
Validated Network Model
      ↓
Numerical Result
      ↓
AI Explanation
```

This separation allows the application to combine natural-language interaction with reproducible mathematical analysis.
